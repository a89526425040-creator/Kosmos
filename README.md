# COSMOS — Space Flight (Godot)

Мобильный 3D-симулятор полёта космического корабля. Проект рассчитан на Godot 4.4 и сборку Android APK через GitHub Actions — локальная установка движка не требуется.

## Первый прототип
- 3D-корабль с корпусом, носовой частью, крыльями и двигателями.
- Сферическая Земля, облачный слой, голубая атмосфера и звёздное поле.
- Свободный полёт с инерцией, основным и реверсивным двигателем, расходом топлива и изменением массы.
- Гравитация Земли и атмосферное сопротивление.
- Управление ориентацией по pitch/yaw/roll и боковые RCS-двигатели.
- Телеметрия: высота, скорость, ускорение, гравитация, плотность воздуха и топливо.
- Сенсорные кнопки и клавиатура для тестирования на ПК.

## Управление
- W/S — тяга вперёд/назад.
- Стрелки — pitch/yaw.
- Q/E — roll.
- Экранные кнопки — тяга, RCS вверх/вниз и крен.
- Перетаскивание пальцем по экрану — управление ориентацией.

## Сборка
Workflow в .github/workflows/android.yml собирает APK при push в main и публикует его как GitHub Actions Artifact. Также доступен ручной запуск из вкладки Actions.

Это первый игровой прототип. Следующие итерации добавят аналоговые виртуальные джойстики, более подробную физику орбит, текстуры Земли и полноценную модель атмосферы.
